# Serzhan Birzhan — Bookshelf

Интерактивті 3D кітап сөресі (React + Vite + Tailwind): Rogers & Farson 1957 *Active Listening*, Education Endowment Foundation 2017 және т.б.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # сборка в dist/
```

## GitHub Pages

1. Залей проект в репозиторий (ветка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. После push сайт соберётся сам: `https://<username>.github.io/<repo>/`
